# wow-links

A compact, verified directory of tools, sites, guides, cheat sheets, videos, and desktop apps for World of Warcraft Midnight Season 2 (patch 12.1) Mythic+ and raid play. Static site, deployed via GitHub Actions to GitHub Pages: https://vosbek.github.io/wow-links/

Includes a personal "My Setup" page listing the addons currently installed on this account, kept separate from the shared directory. The public "Addons" page is intentionally short and curated, not a CurseForge mirror.

## Structure

Multi-page site, one page per category, sharing a common sidebar/topbar and `style.css` (light, neutral-plus-indigo design system — Archivo / Public Sans / IBM Plex Mono, via Google Fonts):

- `index.html` — Overview / landing
- `sites.html` — Sites & Calculators
- `guides.html` — Guides
- `cheatsheets.html` — Cheat Sheets & Images
- `videos.html` — Videos
- `tools.html` — Desktop Tools
- `voice.html` — Voice-Cue Packs
- `my-setup.html` — My Setup (personal loadout)
- `addons.html` — Addons (curated, kept short — bottom of nav)
- `.github/workflows/pages.yml` — deploys `main` to GitHub Pages on push

## Updating

The pages are generated by `scripts/build_site.py` — it renders the shared topbar/sidebar chrome and every page's content list (defined as plain Python tuples near the bottom of the script) into the HTML files, so the sidebar counts, table captions, and per-page totals stay consistent without manual arithmetic. To add, remove, or edit an entry:

1. Edit the relevant list in `scripts/build_site.py` (e.g. `sites_gearing`, `addons`, `setup`).
2. Run `python3 scripts/build_site.py` from the repo root — it overwrites all nine HTML files in place.
3. Check the diff, commit, and push to `main`. The Pages workflow redeploys automatically.

Editing the HTML files directly also works for one-off tweaks, but a regeneration will overwrite them, so prefer the script for anything you want to keep. Links should be checked live before adding; season patches move fast and sites go stale.
